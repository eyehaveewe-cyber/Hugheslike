# Reporting

For every future repository update, maintain the root `UPDATES.txt` and include
its direct GitHub link in the completion message. Keep dated entries newest
first and preserve existing history. Describe user-visible changes, what can be
tried, checks actually performed, remaining limits, and the branch and source
commit in everyday language. Clearly separate implemented work, research-only
findings, and unpublished or unmerged work; link supporting GitHub evidence.

This is a reporting requirement only. It does not authorize feature work,
imports, publication of private sources or assets, merging, or deployment.
