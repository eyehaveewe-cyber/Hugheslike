# Authored graph destination

The bundled seed lives at `addons/hughes_atlas/seed_catalog.json`.
On first use the workspace expands it in memory. **Save** creates
`data/atlas/hughes_atlas.json`; an existing graph is never reseeded over.
The `.bak` beside a saved graph is the previous on-disk version.

Definitions, examples, relation types and layout travel in the same versioned
JSON document. Review any personal notes before committing that document to
this public repository. The seed contains invented people and no private art.
